# IYF S12 Week 5 — DOM and Events

This repository contains the DOM practice exercises, event-handling lessons, an interactive to-do list, and the five daily DOM challenges.

## Pages

- `dom-practice.html` — Lesson 9 selection, traversal, content, attributes, and element creation/removal. Open with Live Server to run `dom.js` and inspect the console.
- `lesson10.html` — event listeners, click counter, event properties, keyboard shortcuts, bubbling, delegated events, and contact-form validation.
- `index.html` — interactive to-do list mini-project with filters, completion, editing, deletion, and remaining-item count.
- `daily-challenges/index.html` — color changer, numbered paragraphs, image controls, content copier, and persistent dark mode.

## Run

Open the desired HTML page with VS Code Live Server, or open it directly in a modern browser. The Lesson 9 practice page intentionally includes an unsafe `innerHTML` injection demonstration; use it only as a local learning example.
